Intro

En este capítulo vamos a conocer algunos conceptos básicos sobre HTML y aprenderemos a utilizar diferentes elementos para crear y organizar una página web. Veremos cómo funcionan los enlaces y las listas y cómo podemos utilizarlos para que una página sea más sencilla de navegar y tenga la información mejor organizada.

Desarollo

Los enlaces en HTML se utilizan para poder pasar de una parte de una página a otra. Para crear un enlace utilizamos la etiqueta y dentro de href ponemos el lugar al que queremos ir. También podemos utilizar enlaces internos para movernos entre diferentes partes del mismo documento, utilizando identificadores como id.

Final

Para terminar, hemos aprendido cómo utilizar los enlaces y las listas en HTML para organizar mejor una página web. Estos elementos permiten que la información sea más fácil de entender y que podamos navegar de una parte a otra del documento de forma sencilla.
